# 세미투어 플래너

여행사 직원이 세미패키지·풀패키지 상품의 **코스 → 견적 → 고객 문서 → 예약·운영**까지 한 화면에서 만드는 웹앱입니다.
AI(Gemini)로 일정 초안·검증·시세 조사를 하고, 결과는 브라우저 또는 서버(Cloudflare KV)에 저장합니다.

- 프레임워크: Next.js 16 (App Router) · React 19 · Tailwind CSS 4
- 배포: Cloudflare Workers (`vinext`로 빌드) — Vercel이 아닙니다
- 저장소: Cloudflare KV (`PLANS`, `AI_CACHE`), 브라우저 localStorage

> 이 저장소의 Next.js는 학습 자료와 다른 부분이 있습니다. 코드를 고치기 전에 `AGENTS.md`를 먼저 읽으세요.

## 처음 실행하기

```bash
npm ci
npm run hooks:install   # 커밋 전 테스트 + 버전 자동 증가 훅 설치 (한 번만)
cp .env.example .env.local   # 값 채우기 (아래 표)
npm run dev             # http://localhost:3000
```

Node 버전은 `.node-version`(22)을 따릅니다. CI도 같은 버전을 씁니다.

## 주요 명령

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 (Next) |

CI(`.github/workflows/ci.yml`)는 푸시·PR마다 타입 검사 → 린트 → 테스트 → Next 빌드 → vinext 빌드 → 브라우저 테스트를 돌립니다.

## 환경변수

로컬은 `.env.local`, 배포는 Cloudflare 대시보드의 **변수 및 암호(Secret)** 에 넣습니다. 키·코드는 반드시 Secret으로 넣으세요.

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| `GEMINI_API_KEY` | ✅ | AI 기능 전체 |
| `ORS_API_KEY` | 선택 | 무료 도로 경로(OpenRouteService). 구글 지도 키가 없을 때 코스 엔진 이동 시간을 실제 도로로 계산. 앱 **AI 키 설정**에서도 입력 |
| `GEMINI_BACKUP_API_KEY` | 선택 | Gemini 예비 키. 주 키가 크레딧 소진(402)·한도(429)·키 오류면 같은 요청을 예비 키로 다시 보냄(막힌 키는 한도 1분·크레딧 1시간 쉼). 예: 무료 주 키 + 결제 연결 예비 키. 앱 **AI 키 설정**에서도 넣을 수 있음 |
| `APP_ACCESS_CODE` | 배포 시 ✅ | 관리자 접속 코드. 비우면 잠금이 꺼집니다(로컬 개발 전용). 스튜디오처럼 다른 사이트에서도 확인할 수 있으므로 **영문·숫자 섞어 12자 이상**을 쓰세요(짧으면 관리자 화면에 경고) |
| `APP_WORKSPACE_ID` | 권장 | 서버 저장 공간 ID 고정(영문·숫자 8~64자). 없으면 접속 코드에서 만들어져, 코드를 바꾸면 저장 데이터가 안 보입니다 |
| `GEMINI_MODEL` / `GEMINI_BASE_URL` | 선택 | 모델(기본 `gemini-flash-lite-latest`)·중계 주소 변경 |
| `GROQ_API_KEY` | 권장 | 대체 AI. Gemini가 한도·크레딧 소진이면 Groq가 이어 받음 (모델: `GROQ_MODEL`, `GROQ_SEARCH_MODEL`, `GROQ_VISION_MODEL`) |
| `AI_PROVIDERS` | 선택 | AI 순서 (기본 `gemini,groq,cloudflare`) |
| `CF_AI_MODEL` | 선택 | Cloudflare Workers AI 모델 (기본 `@cf/meta/llama-3.3-70b-instruct-fp8-fast`) |
| `STUDIO_ORIGINS` | 권장 | 상세페이지 스튜디오 등 AI 중계를 허용할 사이트(쉼표 구분). 비우면 모든 사이트 허용(코드는 여전히 필요) |
| `GOOGLE_MAPS_API_KEY` | 선택 | 이동 시간(Google Routes)·지도. 없으면 거리로 어림 |
| `KAKAO_REST_API_KEY` | 선택 | 국내 차량 길찾기·통행료 |
| `TRAVELPAYOUTS_TOKEN` | 선택 | 항공 최저가 |
| `VIATOR_API_KEY` | 선택 | 투어 판매가·평점 |
| `DATA_GO_KR_KEY` | 선택 | 여행경보 예비 조회 |

설정 상태는 관리자로 로그인한 뒤 `/api/health`(외부 접속 위치까지 보려면 `/api/health?probe=1`)에서 확인합니다. 로그인하지 않으면 버전만 보입니다.

## Cloudflare 설정 (`wrangler.jsonc`)

- `placement.region = aws:us-east-1` — Gemini 지원 지역에서 실행되도록 고정
- `AI_RATE_LIMITER` — AI 호출 제한 (IP당 1분 10회)
- `AUTH_RATE_LIMITER` — 접근 코드 확인 시도 제한 (로그인·스튜디오 공통, IP당 1분 120회)
- `AUTH_FAIL_LIMITER` — 틀린 접근 코드가 IP당 1분 10회를 넘으면 그 IP를 10분 잠금 (잠금 기록은 KV `authlock:` 키)
- KV `PLANS`(일정·예약·직원·견적 요청 등), `AI_CACHE`(스튜디오 AI 중계 캐시) — id를 비워 두면 배포 때 자동 생성

## AI 자동 전환

서버의 AI 호출(`lib/server/gemini.ts`의 `generateJson`, `generateGroundedText`)은 `AI_PROVIDERS` 순서로 시도합니다.

| 순서 | 업체 | 일반 생성 | 웹 검색 조사 | 코스표 사진 | 코스표 PDF |
| --- | --- | --- | --- | --- | --- |
| 1 | Gemini (무료 키, Flash-Lite) | ✅ | ✅ Google 검색 | ✅ | ✅ |
| 2 | Groq (`GROQ_API_KEY`) | ✅ | 🟡 `groq/compound` 웹 검색 | ✅ | ❌ |
| 3 | Cloudflare Workers AI (`AI` 바인딩) | ✅ | ❌ 검색 없음 → "웹 근거 없음" 표시 | ❌ | ❌ |

- Gemini가 붐빔(503)·일시 오류(500)면 2초 뒤 같은 모델로 한 번, 그래도 안 되면 다른 Gemini 모델(`GEMINI_FALLBACK_MODEL`)로 한 번 더 시도한 뒤 다음 업체로 넘어갑니다.
- 402(크레딧 소진)·429(한도)·5xx·시간 초과·키 오류면 다음 업체로 넘어갑니다. 실패한 업체는 잠시 쉬게 합니다(크레딧·키 1시간, 한도 5분 또는 안내된 시간, 장애 1분). 쓸 수 있는 업체가 모두 쉬는 중이면 그래도 시도합니다.
- 대체 업체가 답하면 응답에 `X-AI-Provider` 머리글이 붙고, 화면 오른쪽 아래에 "대체 AI가 답했습니다" 안내가 뜹니다.
- **키 넣는 곳:** 관리자로 로그인 → 상단 **더보기 → AI 키 설정**. Gemini·Groq 키, Gemini 모델, 사용 순서를 바꾸고 업체별 **연결 시험**을 할 수 있습니다.
  - 키는 서버 저장소(KV)에 AES-GCM으로 암호화해 보관하고, 화면에는 끝 4자리만 보입니다. 앱에서 넣은 값이 Cloudflare 변수보다 우선하고, 지우면 Cloudflare 변수를 씁니다.
  - 암호화 키는 `APP_SECRET_KEY`(있으면) 또는 관리자 접속 코드에서 만듭니다. `APP_SECRET_KEY` 없이 접속 코드를 바꾸면 저장한 키를 다시 넣어야 합니다(화면에 안내됨).
- 상태는 관리자로 `/api/health`의 `aiProviders`에서 봅니다(쉬는 상태는 서버 인스턴스마다 따로).
- 상세페이지 스튜디오 중계(`/api/studio/gemini`)는 Gemini 형식을 그대로 전달하므로 자동 전환 대상이 아닙니다.

## 항공 시각에 맞춘 코스 (도착일·출국일)

항공 포함 해외여행은 도착·출국 시각으로 첫날과 출국일에 관광할 시간을 정해 AI가 그날도 짭니다 (`lib/flightPlan.ts`).

- **도착일:** 현지 도착 + 입국·수하물 60분 + 시내 이동 40분 뒤부터 관광 → 저녁 → 호텔 체크인. 18시 이후 도착이면 관광 없이 휴식합니다.
- **출국일:** 체크아웃 → 관광(공항 방향) → 출발 3시간 전 공항 도착(국제선) + 이동 60분 → 귀국편. 귀국편 출발 시각은 고정이고, 관광이 짧으면 체크아웃을 늦춥니다(09:00~11:00).
- **심야 귀국편**(숙박 = 일수 − 2): 마지막 전날 저녁까지 관광하고 공항으로 이동하며, 마지막 날은 귀국편만 넣습니다.
- **항공편 미정:** 노선 비행시간으로 흔한 시각을 가정하고(단거리 09:00·장거리 10:30 출발, 저녁 19:00 또는 심야 00:30 귀국), 항공 줄에 "예상 시각"이라고 표시합니다. 항공편을 고르면 실제 시각으로 바뀝니다.
- **자동 구성:** 코스보다 **항공편을 먼저** 고릅니다. 입력 기간에 맞는 편 중 직항, 오전~점심 도착, 저녁 귀국편, 싼 편 순입니다.
- **빈 시간:** 도착일 오후, 출국일 공항 대기가 2시간 30분 이상 비면 일정 카드에 [추천일정 채우기]가 뜹니다. 출국일은 공항 이동 앞에 넣고 귀국편 시각은 그대로 둡니다.
- **기간:** 숙박을 바꾸면 일수도 따라갑니다. 가까운 노선(비행 5시간 이하·시차 2시간 이하)에서 숙박 + 2일이면 "기내 1박 없음" 경고와 [N박 N+1일로 맞추기] 버튼이 뜹니다.

## 전세버스·가이드 조회 (예상 인원 기준)

원가 직접 입력 → **고정비용**의 **[전세버스·가이드 조회]** (`/api/ground-lookup`, `lib/groundPlan.ts`, `lib/server/groundLookup.ts`)

- 예상 인원으로 차종·대수·가이드 수를 정합니다. 예: 50명이면 중형버스 2대·가이드 2명. 45명을 넘으면 고르게 나누고, 가이드 1명당 인원은 설정할 수 있습니다(기본 45명).
- 요금은 ① 회사 요금표(업체 견적가 180일·같은 시즌 > 웹 시세 30일) → ② 웹 조사(차종 5종 1대 1일 + 가이드 1명 1일, 낮음·보통·높음) 순으로 찾습니다. 웹 시세는 요금표에 쌓입니다. 지난 견적 값은 참고로만 보여 줍니다.
- 낮음·보통·높음 중 기준을 골라 **[견적에 적용]**하면 차량비·가이드비(1일)와 차종별 요금이 들어갑니다.
- **인원별 환산(`groundScale: auto`):** 인원별 가격표, 고객용 인원별 판매가, 손익분기·최소 인원, 원가표에서 인원에 따라 차종·대수·가이드 수가 바뀌면 차량비·가이드비를 그 비율로 바꿔 계산합니다(조회한 차종별 요금이 있으면 그 비율, 없으면 차종 기본 비율). 끄면 지금 금액 그대로 씁니다.

## 무료로 쓰기 (AI 절약·무료 데이터)

- **AI 대체 순서:** Gemini → Groq → OpenRouter(무료 모델) → Cloudflare AI. 키는 더보기 → AI 키 설정에서 넣습니다.
  - Groq·OpenRouter는 계정에서 쓸 수 있는 모델을 조회해 고릅니다(무료 등급 모델이 자주 바뀜). 모델이 없어졌다는 404가 나면 목록을 다시 받아 다른 모델로 시도합니다.
  - Cloudflare는 문맥이 긴 모델(llama-4-scout, 131k)을 쓰고, 입력 길이에 맞춰 답 길이를 줄입니다. 그래도 넘치면 입력 가운데를 줄입니다.
- **웹 검색 대체:** Gemini가 없으면 Groq 검색 모델(있을 때) → Tavily 검색 결과를 근거로 조사합니다(출처 표시). 둘 다 없으면 "웹 근거 없음(추정)"으로 표시합니다.
- **AI 절약 모드 (회사 설정):** 자동으로 도는 AI 호출을 끕니다. 대상은 미리 조회, 경쟁 상품 자동 찾기, 코스 점검 자동 실행, 세일즈 포인트 자동 생성, 지식 창고 미리 조사, 경쟁 상품 정기 확인, 생성 후 자동 견적입니다.
- **무료 공개 데이터 (`lib/server/freeData.ts`):**
  - 좌표: OpenStreetMap Nominatim을 먼저 쓰고, 못 찾은 곳만 AI로 찾습니다.
  - 출발 시기 날씨: Open-Meteo로 작년 같은 기간 날씨를 보여 줍니다. AI가 실패해도 날씨·공휴일은 나옵니다.
  - 문서 번역: AI를 못 쓰면 Cloudflare 번역 전용 모델(m2m100)로 번역합니다.
  - 관광지 조사: 위키백과 주변 문서 목록을 참고 자료로 붙입니다.
  - 공휴일(Nager.Date)·환율(open.er-api)·장소 사진(위키백과)은 원래부터 무료 데이터를 씁니다.

## 상품 링크로 코스 만들기·판매가 역계산

입력 화면 맨 위 **상품 링크로 코스 만들기**에 다른 여행사 상품 링크(네이버 패키지·여행사 상세 등)를 넣으면 `/api/import-product`가 읽습니다(`lib/server/productImport.ts`).

- **읽는 방법:** 서버가 페이지 글·상품 데이터(JSON)·메타 태그를 직접 받고, AI가 그 글과 링크 읽기(Gemini URL 읽기)·웹 검색으로 상품명·여행사·출발일·기간·성인 판매가·항공 시각·날짜별 일정·포함/불포함·쇼핑·선택관광을 정리합니다. 페이지 글 안의 지시는 따르지 않고, 내부망·IP 링크는 읽지 않습니다.
- **[이 상품 기준으로 우리 코스]:** 같은 기간·항공 시각과 주요 방문지(꼭 넣을 것)로 AI가 우리 코스를 만듭니다.
- **[이 상품 코스 그대로]:** 날짜별 일정 원문을 업체 코스로 가져옵니다. 링크에서 읽은 항공 시각으로 첫날(출발·도착)과 마지막 날(귀국편)을 맞추고(원문에 비행 줄이 없으면 만들어 넣음), 점심 무렵 도착이면 점심을 도착 바로 뒤로 당기며, 도착일·출국일 빈 시간만 추천 일정으로 채웁니다(`lib/pasteFlight.ts`). 업체 코스 붙여넣기도 항공 포함·항공편을 골랐으면 같은 방식입니다.
- **출발일:** 네이버 패키지 주소 끝의 날짜(`…/상품코드-20261209`)를 출발일로 쓰고, AI 검색은 그 상품 코드·날짜로만 찾게 합니다. AI가 읽은 날짜가 다르면 다른 날짜 상품이 섞였을 수 있다고 경고합니다.
- **순서 안전장치(`lib/courseOrder.ts`):** 상품 페이지의 날짜 요약(식사·호텔·관광지 목록) 순서로 읽혀 하루가 거꾸로 된 경우만 바로잡고 "순서 바로잡음"으로 알립니다 — 숙박 호텔은 하루 끝, 저녁은 낮 관광 뒤, 출국일 관광·식사는 공항 이동·귀국편 앞, 관광 앞뒤로 몰린 점심은 점심 시간대로. 관광이 있는 출국일은 귀국편 시각에서 거꾸로 계산하지 않고 09:00 출발, 귀국편 시각은 고정합니다.
- **세부 일정:** 링크 읽기는 날짜별 세부 일정(1. 2. 3.) 순서로 일정 원문을 만들고, 요약 목록만 읽었으면 경고하며 [그대로 가져오기]를 막습니다(상세 글을 복사해 업체 코스 붙여넣기로). 코스 분석도 요약 줄과 세부 일정이 함께 있으면 세부 일정 순서를 따릅니다.
- **숙박 호텔·편명:** 일정표 HOTEL 줄은 고른 호텔이 없으면 코스에 적힌 숙박 호텔 이름을 씁니다(링크로 가져오면 예전 상품의 고른 호텔은 비움). 오는 편 편명이 가는 편과 같게 읽히면 비우고 확인 필요로 표시합니다.
- **확인 표시:** 페이지를 직접 읽지 못해 AI가 정리했으면 노란 경고를, 일정 원문의 날짜별 줄 수(내용이 거의 없는 날·일수가 맞지 않음)를 보여 줍니다.
- **역계산:** 두 경우 모두 판매가를 "판매가에서 시작"으로 넣어 목표 마진·수수료를 뺀 1인 원가 예산을 항공·숙박·지상비로 나눠 보여 주고, 그 상품을 경쟁 상품으로 등록합니다.

## 코스 시간·구성 기준 (대형사 관행)

여행 일정 서비스(마이로·Inspirock·Sygic 등)와 대형 여행사(하나투어·모두투어·노랑풍선·교원투어) 패키지 구성을 조사해 넣은 점검입니다(`lib/courseStandards.ts`). 요약·추천에 나오고, 고칠 수 있는 것은 버튼 하나로 고칩니다(되돌리기 가능).

- **표준 체류 시간표:** 하차·포토 10~40분, 관광지 20~120분, 박물관 60~150분, 시장 40~90분, 테마파크 4~9시간, 식사 40~90분(특식 50~120분), 카페 15~50분 등. AI 추정이 범위를 크게 벗어나면 알리고 [표준 시간으로 맞추기]. 웹 확인·직접 입력·업체 표기·지식 창고 시간은 건드리지 않습니다.
- **체류 근거 표시:** 일정 카드의 체류 시간 옆에 직접 입력 / 웹 확인 / 지식 창고 / 업체 표기 / 표준표 / AI 추정.
- **단체 여유:** 15명 이상 장소마다 10분, 30명 이상 15분(승하차·인원 확인·화장실·주차장 도보). AI 코스는 만들 때 자동으로 더하고, 업체 코스는 추천에서 [+10분씩 더하기].
- **이동 시간:** 구글 지도 키가 없으면 무료 도로 경로(OpenRouteService, `ORS_API_KEY` — 앱 AI 키 설정에서도 입력)로 실제 도로 시간을 받고(대형버스 × 1.15), 교통을 모르는 시간표면 출퇴근(07:30~09:30, 17:00~19:30) 차량 이동을 1.3배로 잡습니다.
- **기사 구속 시간:** 일본 전세버스는 미팅부터 해산까지 하루 13시간을 넘으면 경고(실제 적용은 업체 확인).
- **하루 여유:** 8시간 넘는 관광일에 여유(자유시간)가 10%도 없으면 "지연에 약함".
- **한 방향 동선:** 숙박 도시가 되돌아오는지, 장거리 이동일(4시간+) 다음 날 미팅([09:00 출발]), 마지막 밤 숙소와 귀국 공항 거리(100km 넘으면 경고).
- **료칸:** 체크인 뒤 관광, 16:30 넘은 도착, 다음 날 09:00 전 출발을 알립니다.
- **첫날·마지막 날:** AI 코스 지시문에 대형사 관행(도착일은 공항 1시간 안 가벼운 일정 + 자유석식, 출국일은 공항 방향 관광 → 쇼핑 → 점심 → 공항, 특식은 "특식-메뉴명")을 넣었습니다. 회사 설정의 **공항 미팅 안내**가 일정표 첫 줄에 나오고, 저비용 항공이면 "기내식 미제공"을 붙입니다.
- **특식·등급:** 상품 표식에 "특식 N회". 프리미엄·시그니처 등급은 "일정표 밖 비용 보상" 특약을 기본 추천합니다.
- **업체 표기 시간 쌓기:** 업체 코스·상품 링크 원문의 "약 30분 소요"를 지식 창고에 모아, 2건 이상이면 다음 AI 코스의 체류 근거로 씁니다(현장 실측 3건 이상이 가장 우선).
- **타사 구성 비교:** 링크로 가져온 상품의 하루 관광지 수·하루 이동·특식·쇼핑을 우리 코스와 나란히 보여 줍니다.
- **대형사 일정표 형식 복사:** 결과 화면 [텍스트로 복사]에서 날짜 요약(식사·호텔·교통·대표 관광지) + 번호 세부("[도시] - …", 구간 이동 "약 N 소요") 글을 복사해 채널 등록에 씁니다.
- **장소 담아 자동 배치:** 입력 화면에서 넣고 싶은 장소를 한 줄에 하나씩 담으면(최대 20곳) 가까운 곳끼리 날짜를 나누고 코스 엔진이 영업시간·점심·이동 시간에 맞춰 배치합니다(`/api/place-cart`).

## 긴 글 붙여넣기

브라우저 기본 붙여넣기는 글을 한 줄씩 끼워 넣어 1만 자쯤이면 화면이 0.5초~수 초 멈춥니다. 업체 코스·견적서 원문, 가이드 해설집, 현지 회화, 특약, 여행자 명단처럼 긴 글 칸은 1,000자 넘는 붙여넣기를 앱이 직접 받아 한 번에 넣습니다(`lib/fastPaste.ts`, 글자 수 제한·커서 위치 유지). 이렇게 넣은 붙여넣기는 Ctrl+Z로 되돌려지지 않으니 칸을 비우고 다시 붙여넣으세요. 업체 코스 원문 칸은 맞춤법 검사도 끕니다.

## 계약서 특약·취소 규정

- **특약(표준약관 제6조, `lib/specialTerms.ts`):** 대형사 약관에서 쓰는 공통·국가별 특약 21개를 준비해 두었습니다. 여행지에 맞춰 추천하고, 상품마다 "5. 고객·문서"에서 켜고 끌 수 있습니다. 금액·영업시간·회사 고유 특약은 회사 설정에서 정합니다. 계약서 ③ 특약에 "표준약관과 다른 점"과 별도 동의 서명란이 들어갑니다.
- **취소 및 환불 규정(`lib/cancelPolicy.ts`):** 표준약관, 대형사 특별약관형, 선납·전세기형 틀에서 고르거나 구간을 직접 정합니다(전액 환불·예약금·고정 금액·%·환불 불가). 회사 기본과 상품별 설정이 있습니다.
  - 출발일로 구간마다 실제 날짜를 계산합니다. 영업일 기준이면 무료 취소 **실제 마감**(주말·공휴일이면 직전 영업일 업무 종료)을 함께 표시합니다.
  - 일정표·견적서·계약서(특별약관이면 ③ 특약으로 동의)·웹 일정표에 같은 표가 들어갑니다.
  - 특별약관에는 "요청 시 산정 근거 제시, 실제 손해 초과분 환급" 고지가 자동으로 붙습니다.
  - 예약 관리에서 취소 통보 날짜·시각으로 취소료와 환불액(또는 추가 청구)을 계산합니다. 항공 발권 수수료도 포함합니다.
- **무효 위험 점검:** 전부 면책, 근거 없는 환불 불가, 50% 넘는 위약금, 사유 없는 고율 구간, 금액 없는 개런티, 휴일 마감을 입력 화면에서 경고하고, 계약서를 인쇄하기 전에 다시 확인합니다. 실제 계약에 쓰기 전 법률 검토를 권합니다.

## 로그인과 권한

- **관리자**: `APP_ACCESS_CODE`로 로그인. 직원 계정을 만들고 권한을 줍니다.
- **직원(staff)**: 개인 코드로 로그인. 원가·마진까지 봅니다.
- **영업(sales)**: 원가·마진을 숨기고 판매가만 봅니다.
- 로그인 쿠키는 30일 동안 유효하고, 서버에서도 발급 시각을 확인합니다. 접속 코드를 바꾸면 모든 로그인이 풀립니다.
- 틀린 코드를 1분에 10번 넘게 넣으면 그 IP는 10분 동안 로그인·스튜디오 연결이 모두 막힙니다(맞는 코드도 확인하지 않음). 사무실에서 실수로 잠겼다면 10분 기다리면 풀립니다.
